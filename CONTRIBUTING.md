# Contributing to StarPort

Contributions are welcome through pull requests.

1. Fork this repository and create a branch in your fork.
2. Keep the change focused. Use fictional data in examples and tests.
3. Install Node.js 24 or later, run `npm ci`, then run `npm test`.
4. Open a pull request against `main` and describe the change and relevant validation.

The repository owner reviews contributions before they can be merged. Changes pushed after an approval require another review. Contributors do not receive direct write or administrator access to the upstream repository.

Never include conversations, memories, account credentials, local configuration, exports, or native tool history. Report suspected exposed credentials privately using GitHub's private vulnerability reporting when that option is available; do not include secret values in a public issue or pull request.

By contributing, you agree that your contribution will be distributed under the project's [MIT license](LICENSE).
