# 星港 · StarPort

[English](README.md) | 简体中文

<img src="public/icon.svg" width="64" height="64" alt="星港 · StarPort">

星港是 Codex、Claude Code、Antigravity 和 DeepSeek Harness 的本地工作台。对话、房间、共同记忆和项目要求集中在一处，各工具仍使用自己的登录、模型和权限模式。伙伴和工作流让几个 Agent 在同一个对话里协作。群聊（每个人调用自己绑定电脑上的 Agent）还在开发中。

本地工作台不需要星港账号。群聊使用你所选服务器上的账号；模型凭据留在每位参与者自己的电脑上。星港不提供模型订阅，也不在厂商之间转移凭据。

## 亮点

- **提示词随手插入。** 把常用的提示词存起来。发送键旁的 **提示词** 会列出它们，选一条就插到光标处。同一个菜单还能把已经输入的内容存成新提示词，以及重命名、调整顺序和删除。
- **记忆由你自己管。** 四个工具共用一份记忆，不依附任何厂商账号。模型只能提出候选，你确认之后才会记住。条目可以自己添加、修改、搜索和删除；个人偏好和各项目的要求分开管理。每条回复下方的回执会列出这次请求拿到了哪些条目。
- **旧对话一起带过来。** 导入本机的 Codex 历史，也支持 Claude Code、Antigravity 和 DeepSeek，标题、工作文件夹和工具调用记录一并带上。之后在星港里用任何工具接着聊，换工具不用从头再来。

## 开始使用

### Windows

1. 安装 [Node.js 24 或更新版本](https://nodejs.org/)（包含 npm）。安装后重新打开终端或启动入口。
2. 在仓库页面选择 **Code → Download ZIP** 并完整解压，或用 **Code** 菜单里的地址克隆仓库。
3. 双击项目文件夹里的 **Start StarPort.cmd**。首次启动需要联网安装锁定版本的依赖；以后启动会复用。
4. 安装并登录你要用的 Agent 工具。**设置 → 连接与数据** 会显示星港找到了哪些工具，也可以填写程序路径。

工作台地址是 **http://127.0.0.1:3210/**。请在解压后的文件夹里运行启动入口，不要直接在 ZIP 里运行。正常使用不需要 Python，也不需要另外下载 MAGI。

新安装默认使用英文。**设置 → 通用 → 界面语言** 可切换为中文，已保存的选择会保留。只有界面文字会变；你的消息、名称、文件名和工具输出保持原文。

### macOS

要求：macOS 14 或更新版本、Node.js 24 或更新版本，以及 Apple Command Line Tools。如有需要，用 `xcode-select --install` 安装。

```sh
npm ci
npm run install:macos
```

安装器默认在 `~/Applications` 生成 **StarPort.app**。已有安装（包括旧的本地化应用名）会被识别并沿用。从访达或 Dock 打开应用；用 **File → New Window** 或 `⌘N` 打开另一个窗口。关闭窗口不会停止后台任务。详见 [Mac 独立窗口](docs/zh-CN/macos-desktop.md)。

### 手动启动：Windows、macOS 或 Linux

```sh
npm ci
npm run launch
```

每台电脑都需要自己安装并登录 Agent 工具。这个仓库只包含源码、主题资源和测试，不包含对话、记忆、凭据或工具安装。要把自己的记录带过去，见 [导入、导出和换电脑](#导入导出和换电脑)。

## Agent 工具

| 工具 | 接入方式 | 星港中的选项 |
| --- | --- | --- |
| Codex | 本机 Codex App Server（JSON-RPC） | 模型、思考强度、计划与目标模式、目标预算，**请求批准** / **帮我批准** / **完全访问权限** |
| Claude Code | 官方 Claude Agent SDK 驱动本机 CLI | 模型、思考强度、工作方式（包括计划、**自动审核** 和 **跳过权限审批**）、独立 Git 工作树、审批与提问 |
| Antigravity | 本机 AGY CLI 的流式 JSON | 模型、思考强度、对话 / 编辑 / 计划模式、**允许所有工具** 或原生权限、Agent、终端沙箱 |
| DeepSeek Harness | 官方 SDK（JSON-RPC） | 模型、模型服务、思考强度；也支持桌面版自带的 CLI |

只需安装你要用的工具。模型列表和思考强度都来自各工具。星港无法确认某个模型支持什么时，会直接说明，不做猜测。权限选项对应工具自己的模式，原工具仍可执行自己的规则或要求批准。选择工作文件夹并不会建立操作系统级沙箱。

在审批卡片上可以允许或拒绝操作、回答问题，或跳过问题而不授予权限。**查询剩余用量** 显示各厂商自己接口报告的内容，缺少的字段不做估算。星港启动的 Antigravity 会话默认 **允许所有工具**；如需沿用 Antigravity 自己的规则，在 **工具权限** 里选 **遵循原工具权限**。

详见 [Agent 工具：模型、权限与用量](docs/zh-CN/agents.md)。

## 对话

- 侧栏的 **房间** 用来整理对话。同一个房间里的对话可以使用不同的文件夹、工具和模型。
- 工作文件夹就是项目。同一文件夹里的对话共用项目要求和项目记忆；子文件夹是独立的项目。在输入框下方的文件夹选择器里选择或重命名文件夹。
- **执行过程显示** 决定任务过程显示多少：**隐藏**、**概览** 或 **完整**。任务进行中概览保持展开，结束后收进 **查看任务过程**。子代理显示在所属回复里面。星港只显示工具实际报告的内容，不补写未公开的思考。
- 转圈表示对话正在运行；蓝点表示有已完成但你还没看的回复。失败、已停止和未确认结束分别显示。
- 任务进行中发出的消息进入 **等待队列**，可以修改或删除。Codex 和 Claude Code 可以用 **引导** 把排队的消息交给正在运行的任务。排队的消息可以带附件。任务不会仅仅因为没有动静而被停止。
- 已结束回复下方的 **从这里分支** 会新建一个对话，带上到这条回复为止的记录。发送键旁的 **提示词** 可以插入你保存的提示词。每个代码框都有 **复制** 按钮，复制的是原始文本。
- 输入框下方的 **上下文** 显示 Codex 或 Claude Code 最近报告的上下文占用。

详见 [对话、文件与上下文](docs/zh-CN/workspace.md)。

## 长对话的上下文

继续使用同一个工具时，Codex、Claude Code 和 Antigravity 续用各自的原生会话，只接收它们还没见过的消息，并自行管理上下文。需要新会话读取历史时（换了工具或模型、开了分支、改了对话设置之后，以及 DeepSeek 的每一轮，因为 DeepSeek 每次都新建 SDK 会话），星港按每个工具的预算发送历史。放不下时，由写摘要的模型把较早的消息压缩成结构化摘要，保留你自己的要点；模型收到的是摘要加上近期消息的原文。摘要属于这个对话，之后再切换时直接复用；只有新内容又放不下时，星港才会再压缩一次。

没有原文发送的消息保存在工作文件夹里的 `.starport/history/<对话 id>.md`，模型可以读取；`.starport/` 自带 `.gitignore`。**设置 → 上下文** 可以开关自动压缩、设置每个工具的预算（默认 Codex 和 Claude Code 各 10 万 token，Antigravity 和 DeepSeek 各 6 万 token），并选择最多三个写摘要的模型。发给 Antigravity 的每次请求另限 184,000 字节，避免输入被截断。

## 共同记忆与项目要求

星港的记忆独立于厂商账号，四个工具共用。它支持提取候选、确认、在新请求开始时检索，以及在任务中追加检索。个人偏好和项目要求分开管理。

候选需要确认后才成为共同记忆。记忆按与当前请求的相关程度选取，不预设话题列表。模型可以查看候选索引、读取选中的条目，需要更多细节时再检索相关历史。

回复下方的记忆链接会打开这次请求的回执：提供了哪些条目、产生了哪些新候选。它不会把整个记忆库当作全部用过来展示。

- [共同记忆](docs/zh-CN/shared-memory.md)
- [检索架构](docs/zh-CN/memory-retrieval.md)
- [在电脑之间同步记忆](docs/zh-CN/memory-sync.md)

*功能测试中。* 在自己的几台设备之间同步时，选择由你已有的同步服务管理的对应文件夹，例如坚果云、OneDrive 或 Syncthing。星港会创建 `StarportMemory` 子文件夹，运行期间每 15 秒检查一次。已确认记忆、候选、用户画像和已保存的要求可以同步；聊天、附件、登录和工作文件夹留在本地。冲突时保留双方版本供核对。请使用私有的同步文件夹，因为这些文件包含记忆正文和修改历史。

## 房间、伙伴与工作流

房间里还可以住进 **伙伴**：有名字、头像、角色、性格、工具、模型、思考强度，以及无人值守时的工作方式（工具的原生权限模式）。性格只改变伙伴对你说话的语气，不影响它的分析。一位伙伴可以加入任意多个房间。

- **点名**：输入 `@名字` 把任务交给伙伴。只点一位时直接交给它。一条消息点了几位时，先由排程模型排出顺序，例如一位做事、另一位验收。**设置 → 工作流** 里设三个排程模型，依次尝试；都没有响应时按消息里的先后顺序。每位伙伴在每个对话里有自己的工位会话。
- **单向可见** *（功能测试中）*：伙伴只收到这条消息，以及同一次点名里排在它前面的伙伴的结果，看不到对话历史。它的回答照常回到对话里。这是写在指令里的要求，不是技术隔离，因为伙伴和对话共用工作文件夹。
- **工作流** 是由阶段和位置组成的可复用模板。同一阶段的位置并行运行，下一阶段能看到它们的结果。验收位可以把工作退回，最多重做三次。在 **工作流库** 里管理工作流，再挂到任意对话上，为每个位置选一位伙伴。房间外的伙伴会自动加入房间。
- **触发方式**：手动、每天定时（可选星期）或每隔一段时间。定时在星港服务里运行，关掉网页不会停止，但服务没开时不会运行。错过的运行可以补跑一次或跳过。
- **运行卡片** 把每次运行记录在对话里。展开卡片可以跟进每一步、停止运行，或点 **回复**，让你的下一条消息带上这次运行的结果。每次运行都从新的工位会话开始，不读对话历史。
- **台账** *（功能测试中）*（可选，默认关闭）在多次运行之间保存笔记：PLAN、命题、只追加的 CHANGELOG 和检查项，每次运行后提交到 Git。伙伴只能提议修改 PLAN，你确认后才生效。带截止日的预测用 Brier 分数计分。台账放在工作文件夹的 `.starport/ledgers/`，同一文件夹里挂同一工作流的对话共用一份。
- **考场** *（开发中）* 让伙伴在没有对话上下文的情况下各自独立做同一道题。对话模型用 `starport_exam_propose` 提出考试；在你核对提议并点 **开考** 之前，什么都不会复制。每个考位在桌面的 `StarPortExams` 下得到一份自己的试卷，开卷的考位还附带知识库。交卷后星港检查每个考位：哪些文件被改或新增，有没有工具调用越出自己的文件夹。考位不是沙箱：检查只能事后发现问题，不能事前阻止；各工具自己的全局指令也仍会加载。
- **记忆**：在每个房间里，每位伙伴有两个开关：**读长期记忆**（默认开）和 **提记忆候选**（默认关）。伙伴提出的候选必须引用你的原话，仍要你确认。

详见 [房间、伙伴与工作流](docs/zh-CN/rooms-and-workflows.md)。

## 通知与设置

任务完成或出错时，星港会显示一条通知，包含房间、对话标题和简短摘要；点击即打开该对话。在 Windows 上是原生弹窗并响一声短提示音，星港在后台时任务栏按钮会闪烁；其他系统使用浏览器通知。你正在看的对话、你手动停止的任务，以及还有排队消息的任务不提醒。顶栏的铃铛用来开关 **勿扰模式**。

**设置** 汇集全局选项：**通用**（语言和主题）、**通知**（提示音和测试通知）、**工作流**（排程模型、重做次数和单步时限）、**上下文**（压缩和预算）以及 **连接与数据**（工具位置、本机服务器和备份）。

## 群聊与手机

> **开发中。** 群聊、手机端和自行托管的服务器都还没有完成，可能有问题，行为和保存的数据也可能还会变。

打开 **群聊与手机**，选择服务器并登录该服务器上的账号。群主分享服务器地址和邀请码。每个人连接自己的电脑，并选择开放哪些文件夹和工具。

参与者可以互相聊天，也可以在群里调用 Agent。共享的回复全群可见；只有调用者本人能答复自己的审批或停止自己的任务。调用使用调用者自己绑定的电脑和原生模型凭据，不使用其他成员的订阅。

手机端是通过 HTTPS 提供的响应式 PWA。本机的 `127.0.0.1` 地址无法从另一台设备访问。能否安装取决于手机和浏览器；普通网页访问始终可用。仓库不提供原生 IPA、APK 或 HAP 安装包。

可以在 **设置 → 连接与数据 → 本机服务器** 自行托管账号和群聊服务，也可以使用仓库提供的 Docker Compose 和 Caddy 部署。不要把端口 3210 上的私人本地工作台暴露到互联网。

## 文件、网页与字幕

输入框下方的 **＋** 菜单可以附加文件、文件夹、浏览器标签页和视频字幕，还包含 **在项目中工作**、Codex 的 **目标**、**计划模式** 和 **绘图** 画布。文件保存为本地副本，每个最多 8 MB，每条消息最多 16 项、合计 24 MB。文件夹以路径附加，不会复制。文件夹浏览器显示的是运行星港服务的那台电脑上的文件夹。

可选的 [Edge 扩展](extensions/edge) 与星港配对后，可以明确附加一个浏览器标签页，或用浏览器当前的登录读取 B 站字幕。浏览器凭据留在 Edge 里。它只读取你指定的网页或视频，不读取浏览历史、密码框或无关的表单输入。缺少字幕或认证失败时会说明原因，不会编造文字稿。详见 [浏览器字幕指南](docs/zh-CN/browser-video-subtitles.md)。

回复里的本地文件链接可以用默认应用打开。在 Windows 上，右键菜单提供 **打开文件**、**在资源管理器中查看**（选中该文件）和系统的 **打开方式** 选择窗口。有歧义的相对文件名需要你选择。显示消息时绝不会执行文件操作；可执行文件和未知类型会打开应用选择窗口。

## 导入、导出和换电脑

用 **导入对话** 选择本机的 Codex、Claude Code、Antigravity 或 DeepSeek 历史，预览后选择目标房间。Codex 导入在日常使用中；Claude Code、Antigravity 和 DeepSeek 导入还在功能测试中。导入是独立副本，不是实时同步；不继承原生权限，也不会自动运行任务。工具调用作为记录一并导入，不会重新执行；隐藏的思考过程不复制。Claude 导入读取本机 CLI 历史，不读取 Claude 网页端历史。Antigravity 导入读取 `~/.gemini/antigravity-cli`，DeepSeek 导入读取 `~/.dsh/sessions`（或 `DSH_HOME`），都只读不写。星港里还在的对话不会列出，子任务和星港每轮自动开的 DeepSeek 会话也不会列出。

导出单个对话时，在它的菜单里选择 **导出对话**：

- **导出会话文件**（`.starport.json`）*（功能测试中）* 包含这个对话的消息、已有的执行记录和支持的上传附件。在另一台电脑导入，并选择本地工作文件夹。
- **导出 Markdown** 生成可阅读的记录。

会话文件不包含其他对话、共同记忆、账号登录、原生会话绑定、权限或排队任务。工作文件夹里生成的文件需要另外搬。重复导入相同内容会打开已有副本，不会覆盖其他对话。当前上限为每个会话文件 120 MB、每个上传附件 8 MB。

**设置 → 连接与数据 → 导出全部记录** 会生成星港记录的完整逻辑备份；在另一台电脑用 **导入备份** *（功能测试中）* 恢复为新副本（上限 128 MB）。导入的记忆需要核对和确认。工作文件夹、文件夹引用和浏览器连接需要在新电脑上重新设置。备份不能提交到 Git。

删除对话会移除它在星港中的记录和它自己的 `.starport/history/` 存档。附件、生成的文件、工作文件夹、原工具里的历史、导出和备份都会保留，相关内容需要另行检查和删除。普通删除不会自动压缩数据库，也不承诺不可恢复的擦除。

## 本地存储与维护

本地工作台使用 WAL 模式的关系型 SQLite 表。主数据库是 `.data/hub.sqlite`；单个数据库文件是 SQLite 的正常存储方式。WAL 和 SHM 文件是运行中数据库的一部分，不是可以删除的残留。详见 [数据库结构](docs/zh-CN/database-architecture.md)。

日常备份请用逻辑导出。直接复制数据库文件前，先正常停止服务，或使用 SQLite 的一致性备份功能；只复制运行中的主文件可能漏掉已提交的 WAL 数据。

Windows 辅助文件：

| 文件 | 用途 |
| --- | --- |
| `Start StarPort.cmd` | 需要时安装依赖，并启动本地工作台 |
| `Restart StarPort.bat` | 等进行中的对话结束后再重启 |
| `Clean StarPort leftovers.bat` | 明确执行的可选操作：对本地数据库做检查点和压缩 |

删除对话时不会自动运行维护工具。它不能代替逐项检查附件、工作目录或外部备份。任务进行中不要运行维护。

## 主题

主题顺序是 **蔚蓝 → 星港 → 深空**，默认蔚蓝，已有选择会保留。**主页面** 打开当前主题的欢迎页，不会停止正在进行的任务。背景和界面资源都随项目打包在本地；进入对话后装饰背景会压暗以便阅读，并遵循系统的减少动态效果设置。

## 开发

要求：Node.js 24 或更新版本。Python 3.10 或更新版本是可选的，只用于安装技能和生成宿主表。

```sh
npm ci
npm test
npm start
```

测试运行器使用独立的临时文件夹，结束后清理。单个测试限时两分钟；某个测试文件五分钟内没有退出，会显示文件名并停止。只跑部分文件：`npm test -- tests/i18n.test.mjs`。推送到 `main` 或提交 Pull Request 时，GitHub Actions 会在 Windows、macOS 和 Linux 上用 Node 24 运行全部测试。

| 位置 | 职责 |
| --- | --- |
| `src/server.mjs` | 本地 HTTP 接口和静态资源 |
| `src/runner.mjs`、`src/adapters/` | 组装上下文、任务生命周期和各工具适配器 |
| `src/storage.mjs`、`src/compaction.mjs` | SQLite 记录和对话压缩 |
| `src/workflows.mjs`、`src/workflows/` | 伙伴、房间、工作流调度、台账和考场 |
| `public/app*.js` | 主工作台、视图、设置和交互 |
| `public/agents-room.js`、`public/room-*.js`、`public/workflow*.js` | 房间、伙伴和工作流弹窗 |
| `public/i18n.js` | 中英文界面翻译 |
| `public/mobile/`、`src/collaboration/` | 群聊与手机界面、服务和执行桥接 |
| `tests/` | 单元、集成测试和隔离界面测试 |

前端使用按顺序加载的普通脚本，没有框架构建步骤。`node tests/ui-fixture.mjs`（端口 3211）、`node tests/completion-ui-fixture.mjs`（端口 3216）和 `node tests/interactions-ui-fixture.mjs`（端口 3217）会启动使用临时数据和模拟工具的隔离服务。`node scripts/live-check.mjs codex antigravity deepseek` 会对每个工具真实调用一次模型，消耗你的额度。不要让测试连接个人账号或真实历史。

可选的工具入口用 `python scripts/install-skills.py` 安装；移动项目后重新运行。在 Codex 里调用 `$harness-hub`；在其他工具里，让它用 harness-hub 技能打开星港。入口打开的是星港自己的本地界面，不会替换原工具的界面。

星港复用了 MAGI 的宿主注册表，以及随附的 marked、KaTeX 和 Archivo 资源，并保留它们的声明。对话数据库、适配器和工作台前端由本项目实现。完整的 MAGI 仓库不是运行依赖。需要重新生成宿主表时，把固定版本的 [MAGI 2.8.0 源码](https://github.com/Misaka16384/magi/tree/e95f14a4a1601008cee9a00aa2b5e78c49842794) 放进被忽略的 `vendor/magi`，再运行 `npm run sync-magi`。

## 反馈问题

发现 bug，或者希望某个功能换个做法？请[提交 Issue](https://github.com/yutaophysics-crypto/StarPort/issues/new/choose)。bug 报告里写清这些，最容易修：

- 做了什么、预期是什么、实际发生了什么；
- 操作系统、Node.js 版本，以及涉及的 Agent 工具和它的版本；
- 什么时候下载的星港或运行的是哪个提交，以及报错文字或截图。

特别欢迎反馈标着 *功能测试中* 的功能。不要贴出对话内容、记忆、凭据、令牌或私人文件路径，请换成占位文字。
