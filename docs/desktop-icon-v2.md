# Starport desktop icon

Design v2: an actual interstellar docking port, with silver-grey terminal arms surrounding a docked spacecraft. Cyan channel lights guide entry and amber berth lights illuminate the boarding gates. The matte navy tile contains the architecture and vessel, with transparent outer corners. Generated with the built-in imagegen tool; original PNG artwork is preserved without retouching. Windows ICO packaging supplies transparent 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel frames.

Assets: `public/assets/starport-desktop-v2.png` (source), `public/assets/starport-desktop-v2.ico` (Windows), `public/assets/starport-desktop-v2-preview.png` (256px preview). Previous artwork and its prompt remain available in [desktop-icon-v1.md](desktop-icon-v1.md); run the packaging script with `--version v1` to rebuild it.

`scripts/set-desktop-icon.ps1` updates only the existing StarPort shortcut's IconLocation, including legacy localized shortcuts. It first backs up the previous shortcut under `.data/source-backups/desktop-icon-v2-20261007`, verifies launcher properties remain identical, notifies the Windows Shell and exports the icon resolved by the Shell to `.data/desktop-icon-v2-shell.png` for inspection. It does not start or restart the server. Use `-VerifyOnly` to check the current shortcut without changing it. Restore the saved shortcut to undo the change.

Official Windows API references: [SHChangeNotify](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shchangenotify), [SHGetFileInfoW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetfileinfow).

The navy rounded tile itself is matte with subtle depth, not glossy glass or chrome framed. The structure and ship fill the tile with generous margins, entirely contained inside it. ONE isolated icon only, no contact sheet, no desktop mockup. No text, no letters, no labels, no logos, no four-point star symbol, no star-and-orbit emblem, no compass, no planet, no nebula, no cluttered star field, no explosions, no cartoon face, no excessive bloom, no cast shadow outside the rounded tile.
