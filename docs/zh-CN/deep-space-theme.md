# 深空

[English](../deep-space-theme.md) | 简体中文

深空是第三套独立主题。在主题切换里选择它；选择保存在当前浏览器中，刷新后保留。没有保存主题的浏览器仍默认使用蔚蓝。

主视图透过轨道船坞的观景舷窗向外看：银白色的飞船、石墨灰的界面和暖琥珀色的引导灯。欢迎页展示插画，对话页会压暗它。清晰的深色面板把聊天、任务过程、设置和文件夹选择分隔开。

## 实现

- 样式：`public/deep-space.css`，限定在 `html[data-theme=deep-space]` 下。手机端紧凑的主题切换规则由各主题共用。
- 注册：`public/theme.js`，包括主题色、网页图标和按钮状态。
- 插画：`public/assets/deep-space.webp`，1672 × 941，本地加载。
- 图标：`public/assets/deep-space-icon.svg`。
- 使用内置的图像生成工具生成，转换为 WebP，未裁剪。完整提示词：[deep-space-prompt.txt](../deep-space-prompt.txt)。
- 支持两种界面语言、窄窗口和减少动态效果偏好。

最初的主题验证使用独立数据库和模拟适配器，覆盖桌面和手机宽度，检查了欢迎页和对话页、任务过程、公式、代码、设置、菜单、文件夹选择、选择的保存以及横向溢出。这些历史检查不能代替修改后运行当前的测试。

本地视觉测试请用 `tests/deep-space-ui-fixture.mjs`。运行时截图和验证输出放在被忽略的 `.data` 里，不放进公开源码。
