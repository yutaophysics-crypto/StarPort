# 上下文占用

[English](../context-indicator.md) | 简体中文

输入框旁的百分比采用最近一次原生请求的占用，除以**原工具报告的模型窗口**。星港历史交接预算和原工具压缩设置不会改变这个百分比。

点击指示器，可以看到分开的三部分：

1. **模型窗口占用。** 最近一次报告的占用和对应的模型窗口。Codex 采用最近一次请求的 Token 总数，不使用累计消耗。Claude Code 采用输入 Token 加缓存读取和写入，不计输出和子任务总量。这些测量各自遵循原工具的用量口径，不代表不同工具的 Token 数完全等价。
2. **原工具自动压缩。** Claude Code 解析后的压缩策略窗口，或 Codex 配置的压缩触发参考值，以及可用时的配置窗口。这些是参考设置，与上面的分母分开。Claude Code 会预留空间，可能在策略窗口填满前压缩。Codex 的 `body_after_prefix` 压缩线只计算前缀后的新增内容，不能与总占用直接相减。正在运行的工具可能在下次启动时才采用修改后的设置。
3. **星港历史交接。** 设置 → 上下文与压缩里的估算 Token 预算。它控制换模型或修改设置后，新会话接收多少历史。历史超出预算时，星港会整理较早的内容；连续会话的压缩由原工具管理。Antigravity 另有单次输入的字节保护，用于避免已观察到的传输截断，与模型窗口分开。

对话打开时，参考设置通常每 30 秒刷新一次。**刷新参考信息**会重新读取，不发送模型请求、不重置对话，也不修改原工具配置。修改星港预算会更新对应的参考值，不会改变模型窗口占用率。

Codex 在对话的工作目录中通过 `config/read` 读取分层后的有效配置，包括 `model_context_window`、`model_auto_compact_token_limit` 及其计算范围；未报告的模型默认值不作猜测。Claude Code 通过 `getContextUsage({detail: 'summary'})` 读取所选模型解析后的压缩策略。这个临时的元数据会话不恢复任何对话记录、不保存会话，也不逐类调用 Token 计数接口。空会话的用量不会替换真实对话的计数。不支持此接口的旧工具会显示参考信息不可用。

已知占用但原工具未报告模型窗口时，只显示 Token 数，不显示百分比。Antigravity 和 DeepSeek 的接入目前未提供可核对的当前窗口测量，因此显示**暂不支持**。未知数据不会显示成零。如果报告的占用超过所报告的模型窗口，指示器显示**计量异常**，详情保留两个原始数值，不显示不合理的百分比，也不悄悄截成 100%。

用量随原工具事件更新，不随每次输入更新。压缩过程中显示**正在压缩…**，直到收到新的用量报告。模型、工作文件夹或原生会话变化后，旧计数会失效。尚未发送的文字和待转入的历史未计入；这个百分比与账号剩余额度分开，也不是准确的压缩倒计时。
