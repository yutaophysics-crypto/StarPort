# 上下文占用

[English](../context-indicator.md)

输入框旁的百分比，使用最近一次原工具请求的占用，除以**已知且可直接比较的上限中的最小值**：

- 星港的历史交接预算，在“设置 → 上下文与压缩”中调整。
- 原工具报告的模型窗口。
- 可读取的原工具配置窗口或压缩参考上限。

点击上下文指示器，可以查看各项数值，以及本次计算采用的分母。打开对话时会自动刷新这些限制，通常不超过 30 秒；“刷新上下文限制”会立即重新查询。修改星港预算后，指示器也会更新，无需再发一轮消息。

Codex 通过 `config/read` 读取当前对话工作目录下合并后的有效配置，包括 `model_context_window` 和 `model_auto_compact_token_limit`。原工具未提供的模型默认值不作猜测。如果压缩线的口径为 `body_after_prefix`，它只计算前缀之后的新增内容；由于当前占用计算整个请求，该压缩线会单独显示，不纳入最小值。

Claude Code 通过原生 SDK 的 `getContextUsage({detail: 'summary'})`，读取所选模型的压缩策略窗口。这项元数据查询不发送模型消息、不恢复历史会话、不持久化会话，也不调用逐项计数的 Token API。空的元数据会话的占用不会覆盖真实对话的输入计数。旧版工具没有此接口时，会显示原工具限制暂不可用。

分子继续使用原工具的单次请求数据：Codex 为最近一次请求的 Token 总数；Claude 为输入加缓存读写，不含输出。它不是累计计费用量。占用随原工具事件更新，不随每次键盘输入更新。

星港预算用于把历史交接给新会话，并不硬性限制原工具的连续会话，所以占比可能超过 100%。该指标用于对照当前限制，不保证恰在某个数值触发压缩：原工具的预留空间和策略会影响触发点，正在运行的工具也可能要到下一次启动才采用新配置。尚未发送的文字和待转入的历史不计入占用。
