# 个人记忆同步

[English](../memory-sync.md) | 简体中文

星港支持可选的共享文件夹，不需要星港账号。文件由你已有的网盘、文件同步应用或网络共享负责传输。星港没有托管服务、注册流程、厂商密码表单或内置的网盘登录。

## 设置两台电脑

1. 在电脑 A 上打开 **共同记忆 → 跨电脑同步**。
2. 浏览到一个已经由文件同步应用管理的私有文件夹，选择 **开启同步**。星港会创建专用的 `StarportMemory` 子文件夹。
3. 等同步应用把这个子文件夹（包括 `space.json`）传到电脑 B。
4. 在电脑 B 上打开同一处设置，选择对应的 **父文件夹** 并开启同步。两台电脑的本地路径可以不同。共享的 `space.json` 身份让它们成为同一个记忆空间。

先从一台设备开始。不要分别初始化两个互不相通的空文件夹：那样每个都会创建自己的空间。如果空间身份发生变化，星港会暂停，而不是替换本地记忆。重新连接前，请先解决网盘里涉及 `space.json` 的冲突。本地写入或检查成功，并不能证明网盘或另一台电脑已经收到。

星港运行期间每 15 秒检查一次文件夹。**立即同步** 会马上检查。另一台电脑要等外部同步应用传完文件、它的星港检查过文件夹后才会收到变更。文件夹不可用时，本地记录保持不变；下一次检查成功时会记录并导出最新的本地状态。新任务使用最新同步过来的、符合条件的记忆；同步不会改变已在运行的任务的上下文。

## 共享与本地的数据

- 共享：已确认记忆、候选、记忆类型和范围、原话依据和来源标签；已保存的个人偏好和项目要求；项目身份和名称。用户画像由已确认的全局记忆派生。
- 已确认的条目保持确认状态，候选仍是候选。同步是你自己记忆空间的可信副本；单独的备份导入仍需要核对。
- 本地：聊天文字、消息、来源消息链接、原生会话、工具权限、厂商凭据、附件、生成的文件、工作文件夹路径、浏览器状态和未保存的草稿。另一台电脑可以读到来源标题和原话，但要检索原对话，需要另外导入那个对话。
- 项目记忆跟随共享的项目身份。远端项目在本地创建时工作路径为空；可以为对话单独选择它，与该对话的工作文件夹无关。名称相同但身份不同的已有项目保持独立。

同步文件包含明文记忆 **以及不可变的修改历史**，包括之后被删除的条目的旧版本。请选择只有你能访问的文件夹。这不是端到端加密，也不是取证级的擦除。星港自己不会上传到任何网盘；传输由你选择的文件同步工具控制。不要把这个目录提交到星港的源码仓库。

## 冲突与删除

每次修改都会标明它基于哪些版本。并发修改会保留双方版本，而不是按电脑时钟选择。冲突会列出设备名称、时间和内容；选择一个版本并明确确认。有冲突的记忆和偏好在解决之前不会放进新的助手提示词。冲突内容发生变化时，过期的选择会被拒绝，需要重新核对。

删除也是一次会被同步的修改，所以离线的旧副本无法悄悄恢复被删的条目。修改与删除同时发生的冲突会隐藏该条目，并保留双方版本，等你明确处理。对已确认条目的修改和对提议更新的批准仍受保护：基于旧确认版本的提议不能覆盖更新的版本。

**关闭同步** 会保留本地记忆、排队的修改和共享文件。不会删除网盘数据、对话、附件或目录。重新连接到同一个空间会保留之前的因果历史。记忆内容相同的复制备份会尽量关联到已有的远端身份；有冲突的版本和含义不明的重复项需要核对。

## 文件与数据库约定

运行中的 SQLite 数据库留在本地。本地表 `memory_sync_changes`、`memory_sync_entities` 和 `memory_sync_candidate_bases` 记录修改、已应用的状态、冲突和提议的基准版本；本地设置保存所选文件夹和开关状态。发件箱在发布文件之前先保存修改，并重试中断的写入。

`StarportMemory/space.json` 保存空间身份。`changes/<UUID>.json` 文件是不可变、有大小上限、带校验和、记录因果父项的操作。写入方使用单独的临时文件，完成后再重命名；不使用共享的可写快照、分布式 SQLite 访问或按时钟决定冲突胜者。不完整、缺失或无效的文件会被计数并重试，子操作会等待它的父操作。空间和修改子目录拒绝符号链接。这验证的是格式和完整性，而不是攻击者的身份：任何能修改这个可信同步文件夹的人都能提出修改。如果出现意外的文件或版本，请停止同步并检查文件夹。

操作历史会随时间增长。这个面向个人使用的初始版本不会压缩历史，也不会自动擦除。手动整理之前请先保留备份。它是为个人记忆记录设计的，不适合附件归档或无限量的团队吞吐。

以下接口受本地令牌和来源校验保护：`GET/PATCH /api/memory-sync`、`POST /api/memory-sync/run`、`POST /api/memory-sync/resolve`。不会开放新的外部可访问服务器。
