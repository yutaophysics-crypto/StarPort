# 对话、文件与上下文

[English](../workspace.md) | 简体中文

本页介绍星港里的日常操作：文件夹与项目、对话菜单、输入框的 **＋** 菜单、长对话、本地文件链接、导入和通知。

## 第一次对话

选择工具，点输入框下方的工作文件夹选好目录，然后发送消息。侧栏右侧的 **工具** 页会随所选工具变化。左侧的房间用来给对话分组；对话右上角的 **⋯** 菜单可以重命名、移到其他房间或更改工作文件夹。

## 房间、文件夹与项目

房间只负责整理对话。每个对话分别保存自己的工作文件夹、工具和模型，所以一个房间可以包含来自多个文件夹和工具的对话。房间标题旁的 **＋** 直接在该房间新建对话。

按住房间标题拖动，或在房间里拖动对话，可以按你的顺序排列侧栏。拖动时有一条细线标出落点，拖到列表顶部或底部附近会自动滚动；按 **Esc** 取消。选中一项后按 **Alt+↑** / **Alt+↓**，一次移动一格。没拖过对话的房间，仍按最近有动静的排在最上面；拖过一次之后，这个房间就按你排的顺序：有新回复不会再跳位置，新建的对话和从别处移进来的对话出现在最上面。**未分组** 始终在最下面。只支持鼠标和触控笔拖动，触屏上滑动是滚动列表。要把对话移到别的房间，用对话菜单里的 **移动到分组…**。

工作文件夹就是项目，无需另行标记。同一文件夹里的对话共用项目要求和项目记忆，子文件夹是独立的项目。工作流开启[台账](rooms-and-workflows.md#台账)后，台账也存在工作文件夹里。已有对话按当前所在的文件夹归入项目。

点输入框下方的工作文件夹，可以浏览运行星港服务的那台电脑上的文件夹：磁盘、主目录、上一级、名称筛选，或粘贴完整路径。**对话设置** 里也有同样的浏览器。这里只列出文件夹，取消不会改变当前文件夹。只是浏览不会创建项目。

对话更换文件夹时，它自己的 `.starport/history/<对话 id>.md` 存档会随之移动。其他对话的存档、项目标识和共享台账留在原文件夹。存档无法移动时，不会更换文件夹。

文件夹选择器里的 **重命名** 会修改磁盘上的文件夹名，并同步更新星港里用到它或它的子文件夹的所有对话和项目。以下情况会拒绝改名并说明原因：文件夹里有对话正在运行、有文件被其他程序占用，或文件夹里有星港自己的程序或数据。

## 对话菜单与删除

鼠标悬停在侧栏的对话上会显示 **⋯** 菜单；键盘聚焦和触屏下也能打开。菜单可以把对话移到其他房间、新房间或「未分组」，不会切换你正在看的对话，也不会改变它的文件夹、模型或运行状态。

删除对话需要确认，正在运行的对话要先停止。删除会从星港数据库中移除该对话的记录、消息、原生会话绑定和导入来源映射，以及它在 `.starport/history/` 下的存档。附件记录和文件副本、工作文件夹和生成的文件、原工具里的历史、导出和备份都会保留。相关内容请自行检查和删除；星港不会自动扫描或删除。删除不会清理数据库，也不承诺不可恢复的擦除。删除当前打开的对话会回到新对话，并清除浏览器里该对话的草稿。

## 提示词、分支与代码

- **提示词**：发送键旁的文档图标列出你保存的提示词，点一条即插入到光标处。同一菜单可以把当前输入存为提示词，也可以新建、改名、排序或删除提示词。提示词保存在星港数据库里。
- **从这里分支**：鼠标悬停在已结束的回复下方，点 **从这里分支**。星港会新建一个对话，复制到这条回复为止的记录，房间、工具、模型和工作文件夹与原对话相同。新对话发出第一条消息时，复制来的记录作为上下文交给模型。
- **复制**：鼠标悬停在代码框上，右上角会出现 **复制**。复制的是原始代码，TeX 的反斜杠和 `$$` 原样保留。

## 公式

回复支持 `$...$`、`$$...$$`，以及旧消息里的括号式分隔符。先保护公式再解析 Markdown，所以公式里的等号、竖线和下划线不会被误当成标题、表格或强调。代码块和行内代码保留原文。长公式在自己的区域内横向滚动。不完整或不支持的公式按原样显示，不影响相邻正文；存储的消息不会被修改。

## 长对话与压缩

继续使用同一个工具时，Codex、Claude Code 和 Antigravity 续用原生会话，并自行管理上下文。以下情况需要新会话读取历史：换了工具或模型、开了分支、改了对话设置，以及 DeepSeek 的每一轮。历史放不进该工具的预算时，由写摘要的模型把较早的部分压缩成结构化摘要，逐条保留你的要点。模型收到的是摘要加上近期消息的原文。

摘要属于这个对话。换模型时直接复用；只有新内容又放不下时，星港才会再压缩一次。压缩进行时，对话区和底部状态栏会显示 **正在压缩上下文…**。

没有原文发送的消息会写入工作文件夹里的 `.starport/history/<对话 id>.md`，开着沙箱的工具也能读到；`.starport/` 自带 `.gitignore`。模型还可以用星港的历史工具搜索和读取完整的本地记录。

**设置 → 上下文** 可以设置：

- 自动压缩的开关。关闭时只附带放得下的最近消息。
- 每个工具新会话的预算。默认 Codex 和 Claude Code 各 10 万 token，Antigravity 和 DeepSeek 各 6 万 token。
- 最多三个写摘要的模型，依次尝试。

发给 Antigravity 的每次请求另限 184,000 字节。这是星港为避免输入被截断设的保护值，不是模型的限制。

## ＋ 菜单

- **文件和文件夹**：选择或拖放文件、粘贴图片，或浏览文件夹。文件保存为本地副本；文件夹以路径附加，不会改变工作文件夹。每项最多 8 MB，每条消息最多 16 项、合计 24 MB。
- **附加 Microsoft Edge**：首次在 `edge://extensions` 加载 `extensions/edge`，在星港菜单里生成配对码，再在扩展里连接。之后就能在星港里选择标签页，正文成为可预览的附件，只有发送时才交给模型。网页读取权限由你在扩展里授予。星港不读取浏览历史、密码框或表单输入，也不自动操作浏览器。配对令牌与星港主界面的令牌分开。
- **读取视频字幕**：四个工具都能用。在菜单里输入 B 站链接或 BV 号，或直接在消息里发送，星港会在发送前通过已连接的 Edge 读取字幕。支持 `?p=2` 这样的分 P。优先中文字幕，自动生成的字幕会标注，保留时间戳。登录留在 Edge 里，带签名的字幕地址不会交给星港或模型。每条消息最多 3 个视频，每个视频的字幕最多 90,000 字符，附件文字合计不超过 100,000 字符；超出上限不会附加截断后的内容。缺少字幕、需要登录或读取超时时，草稿保留，星港会说明原因；不会用简介代替字幕，也不声称完成了音频转写。详见 [浏览器字幕指南](browser-video-subtitles.md)。
- **在项目中工作**：列出已有的项目文件夹，在其中新建对话，也可以选择新的工作文件夹。房间可以单独选择。
- **目标**：Codex 原生的目标模式，可设置可选的预算，从下一条消息开始执行。
- **计划模式**：Codex、Claude Code 和 Antigravity 各自的原生计划模式。DeepSeek 的 SDK 没有对应接口，因此对它禁用。
- **绘图**：鼠标或触控画布，支持颜色、粗细、橡皮擦、撤销和重做。画好的图作为 PNG 附加。Codex、Claude Code 和 DeepSeek 以原生图片形式接收；Antigravity 接收文件路径。

## 打开回复里的本地文件

回复里的 `file:///` 链接、Windows 绝对路径、相对路径和 `PROJECT_NOTES.md` 这样的普通文件名都可以点击。点击会用 Windows 默认应用打开。右键菜单提供 **打开文件**、**在资源管理器中查看**（打开父文件夹并选中该文件）和 **打开方式**（Windows 原生的应用选择窗口）。附件也有同样的右键菜单，左键仍是预览。菜单支持 Shift+F10、方向键和 Esc。

相对路径和裸文件名先在对话的工作文件夹里查找。找不到时，星港会在子文件夹里查找相同结尾的路径；例如 `preview.html` 能找到 `game/preview.html`。完整搜索后只有一个匹配时直接打开，有多个匹配时列出来供你选择。绝对路径和指向上级文件夹的路径不做这种查找。搜索不跟随符号链接或目录联接，也不会离开工作文件夹。搜索在 5 秒、50,000 个条目或 50 个候选后停止；搜索不完整时，只能从已找到的结果里选择，或填写完整路径。代码块、公式和网页链接不会变成文件按钮。

脚本、程序和无法识别的文件类型会打开应用选择窗口，所以点击代码文件不会运行它。文件操作只通过经过认证的同源请求发出，显示消息时绝不执行。文件名作为数据传递，不拼进 Shell 命令。只支持本机的普通文件，不支持网络路径和设备路径。打开文件不会修改对话、附件、备份或文件本身，也不改变文件关联。使用的 Windows 接口：[SHOpenFolderAndSelectItems](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenfolderandselectitems) 和 [SHOpenWithDialog](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shopenwithdialog)。

## 导入历史

> **功能测试中：** 从 Claude Code、Antigravity 和 DeepSeek 导入还没有在实际工作中用过。Codex 导入在日常使用中。

**导入对话** 读取本机的 Codex、Claude Code、Antigravity 或 DeepSeek 历史。搜索、预览并勾选对话，再放进已有或新建的房间。Codex 可以包含已归档的记录；其他来源可以按标题或原目录搜索。Claude 历史通过官方 Agent SDK 从本机的 `.claude/projects`（或 `CLAUDE_CONFIG_DIR`）读取，按每条记录的消息链恢复，不调用模型，也不需要账号可用。不读取 Claude 网页端的历史。

Antigravity 历史从 `~/.gemini/antigravity-cli` 下的对话索引和完整记录读取，DeepSeek 历史从 `~/.dsh/sessions`（或 `DSH_HOME`）读取，都只读不写。星港里还在的对话和子任务不会列出，星港每轮自动开的 DeepSeek 会话也不会列出。由星港发起、但星港里已经没有的 Antigravity 对话会标为 **星港发起**；导入时去掉星港附加的说明，并把当时转交的历史还原成消息。

导入保留双方的文字、标题、工作文件夹和可用的时间，以及工具调用记录（只作记录，不会重新执行）。图片、音频和文件保留为引用；隐藏的思考过程和子代理的内部消息不复制。导入是独立副本，不续写原对话，也不继承原来的权限或目标。导入的 Claude 对话从计划模式开始，Codex 对话从 **请求批准** 开始。如果原文件夹已不存在，请在星港里重新选择工作文件夹。

每种来源分别去重，导入来源映射会随星港备份保存。对话完整读取后才保存，失败不会留下半段记录。导入 Codex 需要支持 `thread/turns/list` 的版本。上限：每个对话的文字 64 MB，每条消息 200 万字符，每个 Claude、Antigravity 或 DeepSeek 原记录文件 128 MB。超出时报错，不会截断。

## 把对话搬到另一台电脑

> **功能测试中：** 已经实现，也有自动测试覆盖，但还没有在两台真实电脑之间用过。

点对话右上角的 **↗**，或侧栏里的 **⋯ → 导出对话**，再选 **导出会话文件**（`.starport.json`，可在另一台电脑恢复）或 **导出 Markdown**（供阅读）。会话文件只包含这一个对话：消息、时间、已保存的过程、上传的图片和文件，以及网页附件的正文。导出正在运行的对话会保存当时的快照，未完成的输出标记为已中断。

在另一台电脑上选择 **导入对话 → 星港会话文件**，预览文件，然后选择房间和本地工作文件夹。导入会建立独立副本，使用那台电脑上的工具登录；历史会交给新的原生会话，不会自动运行任务。上传的附件随文件迁移；工作文件夹里生成的文件需要另外搬，文件夹附件需要重新添加。上限：每个会话文件 120 MB，每个上传附件 8 MB。共同记忆通过 [记忆同步](memory-sync.md) 或完整备份迁移。

## 通知

任务完成或出错时，通知会显示房间、对话标题和一两行结果；点击即打开该对话。在 Windows 上是右下角的原生弹窗，10 秒后自动关闭，并响一声短提示音；星港在后台时任务栏按钮会闪烁。其他系统使用浏览器通知。

点名伙伴的消息，要等它点名的所有人都做完（写了 `@主模型` 的话也包括主模型）才提醒一次。你正在看的对话、你手动停止的任务，以及还有排队消息要处理的任务不会提醒。顶栏的铃铛用来开关 **勿扰模式**。**设置 → 通知** 可以关掉提示音或发送测试通知。

## 布局与主页面

在桌面端拖动面板之间的边界可以调节宽度，双击恢复默认。聚焦边界后，左右方向键调节宽度，Home 或 0 重置。宽度保存在浏览器里；窗口变窄时会自动限制，给对话留出空间。

侧栏 **新对话** 下方的 **主页面** 会打开当前主题的欢迎页，右上角可以切换主题。点 **返回对话** 或按 Esc 回到原来的工作，草稿、光标位置和附件保留，正在运行的任务继续。在手机上，先展开左上角的菜单。
