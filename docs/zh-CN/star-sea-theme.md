# 蔚蓝

[English](../star-sea-theme.md) | 简体中文

视觉主旨：安静的夜港，银蓝色海面上方是开阔的星空；深色的阅读区域和浅蓝色控件让工作台保持平静。

内容安排：左侧保留独立的对话分组，中间是正在进行的对话，右侧是 Harness 选项。新对话页面露出插画；进入对话后插画会压暗。不加装饰性的产品文案，也不改变现有行为。

交互主旨：简短的错落入场欢迎动画、轻微的悬停和聚焦高光，以及简短的菜单和对话框展开效果。没有持续的粒子动画或背景视频。遵循系统的减少动态效果设置。

主题变量在 `public/star-sea.css` 中，在基础布局之后加载。原有的响应式布局保持共用。绘图和图片预览保留原始颜色；草图画布保持白色。

背景图：`public/assets/star-sea.png`，使用内置的图像生成工具生成。完整提示词：`docs/star-sea-prompt.txt`。
