# 共同记忆、偏好与历史检索

[English](../shared-memory.md) | 简体中文

星港的记忆独立于厂商账号。在侧栏打开 **共同记忆**。带索引的记忆条目、要求和派生的 FTS5 索引都保存在现有的关系型 SQLite 数据库中。不需要外部记忆服务，不需要修改厂商配置，也不会写入 Codex 的全局记忆。

## 四层结构

1. **发现与核对。** 助手提出稳定的事实、偏好、目标、价值观和项目知识，并附上该任务中你的原话。新条目和更新在你确认之前都是候选。能否发现取决于模型的表现；不会另外发起付费的总结请求。
2. **调用。** 新请求会收到一份检索指引和有限数量的候选指针，以及你明确保存的个人偏好和项目要求。当前任务的模型判断哪些适用，只读取必要的已确认记忆正文。四个适配器走同一条路径，工作中也能追加检索。未确认的候选无法被这些读取工具读到。
3. **检索原始细节。** 工具可以搜索星港的对话记录，读取有限长度的片段，并链接到原消息。已导入的记录也能搜索。原工具里隐藏的历史不会被扫描，也不会自动放进提示词。
4. **区分范围。** 全局记忆和偏好适用于整个星港；项目记忆和要求只适用于该项目里的对话。每个具体的工作文件夹自动就是一个项目：选择同一文件夹的对话共用它，子文件夹是独立的项目。侧栏的分组只用来整理对话。已有对话会迁移到当前文件夹对应的项目，原有的项目 ID、记忆和要求不会丢弃。

## 界面

- **候选记忆** 显示提议的文字、你的原话、来源，以及更新时的原记忆。可以在 **确认并共享** 前修改或忽略。确认会原子地替换原条目；如果版本已过期，会失败，而不是覆盖更新的修改。
- **已确认** 支持新增、修改、按范围筛选、搜索和删除。**用户画像** 包含已确认的全局事实、偏好、目标和价值观，不包括项目条目和未确认的推断。
- **个人偏好** 和 **项目要求** 有各自的编辑器和本地草稿。草稿在关闭再打开、切换面板时都会保留，直到刷新页面。明确保存的要求从下一个任务开始生效。
- 对话的项目就是它的工作文件夹本身，没有标记步骤，也没有单独的项目选择器。浏览文件夹不会创建项目。文件夹里有一个很小的 `.starport/project.json` 身份标识（`.starport/` 会让 git 忽略自己），所以在星港以外重命名或移动的项目能被重新找到；复制出来的文件夹会得到自己的身份。在文件夹选择器里重命名文件夹，会更新其中所有对话和项目的路径。没有本地文件夹的旧项目保留它们的记忆和要求，可以重新关联。对话的文件夹第一次成为项目时，原生会话会保留：它此前只有全局上下文，项目要求会随每一轮送达。输入框上方的项目标签可以打开它的要求。
- 更换对话的工作文件夹只会搬迁它的历史存档；身份标识、共享的工作流台账和其他对话的存档留在原文件夹。目标位置的准备和数据库更新失败时会回滚。启动时会按已知的会话工作路径修复旧版本遗留的文件。旧文件清理失败会被记录下来，留待重试和删除对话时处理。内部的工位和考位不会创建普通项目。
- **历史搜索** 可以手动搜索非项目对话、指定项目或全部记录。可以读取片段，或打开并高亮原消息。
- 记忆设置分别控制调用、候选发现和助手的历史搜索，默认都开启。助手的提议始终需要确认。你保存的要求是明确的设置。
- 每个回答的回执统计实际读取的完整记忆条目。**检索预览** 单独列出检索过程中看到的索引条目和片段；匹配不代表被使用。完整读取会在记录的元数据中包含模型给出的相关理由和版本。旧回执仍可查看。

不会自动推断身份或性格，不会挖掘原工具的历史，也不会另外发起模型请求。模型仍可能漏提某条记忆，或没有遵循某个偏好。

## 各工具的传输方式与边界

| 适配器 | 实际传输方式 |
|---|---|
| Codex | App Server 的 dynamicTools 和 item/tool/call |
| Claude Code | 官方 Agent SDK 进程内的 starport_context MCP 服务器，只允许五个星港上下文工具 |
| Antigravity | 原生命令工具通过一个临时的、限于本次任务的回环桥运行 scripts/context-tool.mjs |
| DeepSeek Harness | 同一个辅助脚本，通过 SDK 子进程环境继承 |

工具：starport_memory_search、starport_memory_read、starport_history_search、starport_history_read、starport_memory_propose。

AGY 和 DeepSeek 的检索需要原工具允许执行这个辅助脚本并访问它的文件和网络。原生沙箱和命令限制仍然生效，权限模式不会被放宽。如果不可用，提示词会让模型如实报告，而不是编造结果。原工具的全局 MCP 配置不会改变。

临时桥使用随机凭据，拒绝来自浏览器源的请求，只开放限定范围的读取和未确认的提议，任务结束即关闭。它无法访问主应用的接口。原生的动态工具和 MCP 工具使用同一个宿主。

范围来自当前对话：项目工具不能选择其他项目；非项目工具只搜索非项目对话。这限制的是这些工具，而不是一个本已获得授权的原生 Agent 对文件系统的访问。历史文字是资料，不是新的指令，也不能证明当前偏好发生了变化。提议的依据必须来自该任务中实际提供的你的输入。

## 上限与上下文变化

没有话题分类、话题门槛或固定的同义词表。通用的语料索引使用 Unicode 分词、汉字二元组以及按长度和频率的排序，分词结果按记录版本和确认周期缓存。初始提示最多包含八个 ID 和标题，从不包含记忆正文。简短的追问会使用本对话中最近一条有实质内容、已送达的用户消息；助手的输出、排队的消息和其他对话不会作为这些提示的种子。搜索返回有限的标题和片段候选；空查询按标题翻页浏览，可按记忆类型筛选。任务模型通过改写查询或浏览来弥合同义词和语言差异，判断记忆本身的适用条件，并明确读取合适的记录。不相关的关键词匹配不会被自动注入。不需要单独的选择模型、外部记忆服务或嵌入向量凭据。这是字面候选检索加上当前模型的语义判断，而不是向量索引；陌生的措辞可能需要改写查询或浏览，模型也可能跳过检索或选得不好。见 [开放式记忆检索](memory-retrieval.md)。

每个任务允许 12,000 字符的检索预览，最多读取 30 条不同的完整记录，序列化正文累计不超过 9,000 字符，每次读取最多八个 ID。每次读取都会重新检查确认状态、项目归属、删除和同步冲突。因预算省略的内容不计为完整读取。明确保存的偏好和要求文档另有 12,000 字符的额度，并且仍只作用于它们保存的范围。关闭共同记忆会同时阻止搜索和读取，但不会删除已保存的记录。

FTS5 三元组只索引已完成的用户和助手消息，不索引流式增量。失败的消息和未送达的引导不在其中。搜索词作为字面 SQL 参数传入；结果限定范围并分页。读取最多返回 20,000 字符，并给出续读位置。每个任务最多调用 80 次记忆和历史工具。消息元数据会记录调用过的 ID、要求版本、候选和历史来源。工具调用显示在现有的任务过程视图中；不会重建原工具私有的推理。

已确认记忆的修改和删除、调用设置、要求、项目归属以及调用策略版本都会影响原生会话的指纹。需要时，下一个任务会创建新的原生上下文，并根据星港历史重建。retrieval-v3 升级不会续接带有旧版自动记忆正文或缺少新工具定义的原生会话。进行中的任务保留原来的上下文，按需读取时取的是当前符合条件的记录。原生目标属于它原来的会话；目标暂停期间发生的变化，需要在继续时使用新的原生会话。已经发送的文字可能留在旧对话和原生记录中；检索不会删除记忆，也不会改写历史。

保留在结尾的 starport-memory 围栏 JSON 数组仍是提议的后备方式。它在显示时隐藏，并经过校验。无效的提议不能确认记忆，也不能改变权限。如果任务之后失败，工具提出的提议可能仍然保留，但仍需要确认。

## 删除与备份

删除一条记忆只删除它所在的行。内容摘要用来避免已忽略的提议被自动重复提出，且不保存明文；你仍可以手动添加。这是普通删除，不是取证级的擦除。

删除来源对话会移除它派生的搜索条目，清空来源指针，并保留独立保存的记忆和依据。删除或搜索记忆不会删除附件、工作目录、生成的文件、备份或原工具的历史。

导出包含记忆、要求记录和项目归属。导入兼容旧的 v1/v2 备份，会重新映射项目 ID，并把记忆恢复为候选。导入的偏好和要求显示为待保存的内容，需要保存才会生效。已有的有效要求继续生效。来源指针不会被盲目复用。格式错误的导入会整体回滚；共享设置保持不变。

## 本地接口

可选的多台电脑共享使用你自己的同步文件夹，不需要星港账号。见 [个人记忆同步](memory-sync.md)。运行中的 SQLite 文件留在本地；同步有单独的开关、明确的冲突处理，并保留候选的确认流程。

以下路由沿用回环地址、来源和令牌保护：

- GET /api/memories?view=confirmed|candidate|profile&project=<id-or-global>&search=&offset=0&limit=50
- POST /api/memories：kind/title/content，可选 project_id/supersedes；confirmed:true 表示明确的手动保存。替代旧条目的更新仍是候选。
- GET/PATCH/DELETE /api/memories/:id；修改需要提供 revision。
- PATCH /api/memories/config：布尔值 enabled/capture/search。
- GET/PATCH /api/context/preferences；写入需要 content/revision。
- GET/PATCH /api/projects/:id/requirements；同样的版本约定。
- POST /api/context/history/search：query，可选 projectId/all/offset/limit。
- POST /api/context/history/read：chatId，可选 messageId/projectId/all/start/maxChars。
- GET /api/projects；POST /api/projects {workspace} 在第一个对话之前添加文件夹；POST /api/projects/:id/attach {workspace} 重新关联旧的或丢失的文件夹。旧的取消标记接口返回 409，因为文件夹和项目已不可分割。
- POST /api/folders/rename {path,name}：在磁盘上重命名文件夹，并更新其中所有星港路径；其中有对话正在运行时拒绝。
- PATCH /api/chats/:id 不再接受 project_id：项目跟随工作目录。

独立运行的厂商应用和 CLI 不会自动获得星港的记忆。这里实现的是共享上下文，不是自主编排，也不是实体硬件。
