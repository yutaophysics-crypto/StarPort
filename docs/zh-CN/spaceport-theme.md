# 星港主题

[English](../spaceport-theme.md) | 简体中文

这个主题描绘的是星际飞船港，而不是海港。它与 [蔚蓝](star-sea-theme.md) 和深空并存。选择保存在 `localStorage['starport-theme']`；新浏览器默认使用蔚蓝，之后的选择会保留。

## 文件

| 文件 | 职责 |
| --- | --- |
| `public/theme.js` | 在首帧绘制前应用已保存的主题；更新主题色、图标和按钮状态 |
| `public/spaceport.css` | 限定在 `html[data-theme=port]` 下的主题规则 |
| `public/assets/spaceport.svg` | 手写的欢迎页插画：轨道船坞、进港的穿梭机和行星地平线 |
| `public/assets/spaceport-icon.svg` | 八角舱门、轨道环、星点和琥珀信标 |

蔚蓝的样式和插画保持独立。

## 视觉语言

- 深蓝黑和石墨色的底面：`#05070c`、`#080c12`。
- 青色 `#5fd8ff` 表示选中和可用；琥珀色 `#ffb347` 表示运行中；绿色 `#6ff0b0` 表示在线或已完成。
- 输入框、工具面板、对话框和菜单带有细线 HUD 角标，聚焦和悬停时更醒目。
- 主要操作按钮使用切角，同时保留可见的键盘焦点。
- 小号品牌字、分组标签、工具名称和时间使用 Cascadia Mono。
- 对话页背景压暗，叠加一层淡淡的 56px 网格。
- 开启减少动态效果时关闭信标动画。

## 添加主题

1. 在 `public/theme.js` 中注册颜色和图标。
2. 新建样式表，把规则限定在 `html[data-theme=<名称>]` 下。
3. 在 `public/index.html` 中添加主题选项，并在 `public/i18n.js` 中添加它的翻译。
