# 星港主题（Starport）

[English](../spaceport-theme.md) | 简体中文

“星港”原本想表达的是未来的星际飞船港，而不是海港。这个主题和 [蔚蓝](../star-sea-theme.md) 并存，可以在顶栏的“星港 / 蔚蓝 / 深空”开关里切换，选择保存在 `localStorage['starport-theme']`。新安装默认使用蔚蓝主题，已有主题选择会保留。

## 文件

| 文件 | 作用 |
|---|---|
| `public/theme.js` | 在 `<head>` 里同步加载，首帧之前就给 `<html>` 设好 `data-theme`，同时切换 `theme-color` 和网页图标，并处理开关点击 |
| `public/spaceport.css` | 所有规则都限定在 `html[data-theme=port]` 下（CSS 嵌套），选择蔚蓝时整份文件不生效 |
| `public/assets/spaceport.svg` | 欢迎页背景：从观景窗看出去的轨道船坞、进港航线上的穿梭机、行星边缘和窗框。手写 SVG，没有用滤镜，可以直接改 |
| `public/assets/spaceport-icon.svg` | 星港主题的图标：八角舱门、轨道环、星点和琥珀信标 |

`star-sea.css` 和 `assets/star-sea.png` 没有改动。

## 视觉语言

- **底色**：深空黑蓝和石墨船体（`#05070c`、`#080c12`），所有面板都不透明，长时间阅读也不累。
- **信号色**有固定含义：青色 `#5fd8ff` 表示选中、可用；琥珀 `#ffb347` 表示运行中，例如运行中的对话、工具调用和停止按钮；绿色 `#6ff0b0` 表示在线、完成。
- **HUD 角标**：输入框、工具卡片、对话框和菜单的四角有细线角标（`--hud`，悬停或聚焦时换成 `--hud-hot`）。
- **切角**：主按钮（发送、完成、新对话）用 `clip-path` 切掉两个角，焦点框放在按钮内侧，键盘导航时仍然看得见。
- **等宽小字**：品牌副标题、分组标题、工具标签和时间使用 Cascadia Mono 等宽字体、大写、加宽字距，像站内标识。
- **对话页**：背景降到 13% 亮度，叠一层很淡的 56px 仪表网格。
- 开启了“减少动态效果”的系统会关掉信标闪烁（沿用 `star-sea.css` 里的 `prefers-reduced-motion` 规则）。

## 再加一个主题

1. 在 `theme.js` 的 `themes` 里加一项，填上颜色和图标。
2. 新建一份样式表，把规则限定在 `html[data-theme=<名称>]` 下。
3. 在 `index.html` 的 `.theme-switch` 里加一个按钮，在 `i18n.js` 里加上它的英文翻译。
